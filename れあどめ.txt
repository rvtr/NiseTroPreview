初めに
　このプログラムは、ピピン氏が作成し開発された偽トロキャプチャのプログラムソースを改変し作成されています。
　ソースについては、自由に変更して構いませんが、ブログの方に「改良版が作られたら自分も参考にしたいので、一応、こっちのブログにコメが欲しいですね。」とあるので公開する場合は、一報するといいかもしれません。
　
　ピピン氏のブログ
　偽トロキャプチャと車とかとか	http://pipin.blog.eonet.jp/

注意事項
　・拡大／回転機能にDirectX9を使用するようにしました。DLLファイル(D3D*.dll)が無い場合は以下のURLからランタイムをインストールして下さい。
　　http://www.microsoft.com/downloads/details.aspx?displaylang=ja&FamilyID=2da43d38-db71-4c1b-bc6a-9b6652cd92a3

開発ツール＆ライブラリ
　Microsoft Visual C++ 2008 Express Edition
　Microsoft DirectX SDK (November 2008)
　Microsoft Windows SDK v6.1
　MSXML 4.0
　ffmpeg r20986
　　configureオプション
　　--target-os=mingw32 --cc=gcc-sjlj --disable-mmx --disable-debug --disable-static --enable-shared --enable-memalign-hack --disable-ffserver --disable-ffplay --extra-cflags=-fomit-frame-pointer --enable-w32threads

コマンドライン
　--dropframe           エラーフレームの描画方法を表示しない
　--topwindow           常に手前に表示する
　--space 数字          画面の隙間を指定
　--scale 数字          画面の拡大率を指定
　--rotation-left       左回転させて表示する
　--rotation-right      右回転させて表示する
　--scrsel-top          表示画面の選択(上画面)
　--scrsel-bottom       表示画面の選択(下画面)
　--scrsel-double       表示画面の選択(2画面)
　--frameskip-60fps     フレームスキップ(60fpsで表示)
　--frameskip-30fps     フレームスキップ(30fpsで表示)
　--frameskip-20fps     フレームスキップ(20fpsで表示)
　--frameskip-15fps     フレームスキップ(15fpsで表示)
　--cusb2id 数字        カメレオンＵＳＢ FX2のIDを選択
