偽トロキャプチャのキャプチャーデータフォーマットについて

初期版のデータフォーマット("読んだ方が良い.txt"より抜粋)

>RGB３バイトのRAWデータです。
>各バイトデータにRGBデータが6ビットずつ格納されています。
>各バイトデータの先頭ビットはフレームスタート(Vsync)です。
>先頭ビットが1になったタイミングから256x192または256x384ドット分のデータが１画面分。
>先頭ビットは30ピクセル分ほど1になってます。 

>1byte    2byte    3byte    4byte    5byte
>V0RRRRRR V0GGGGGG V0BBBBBB V0RRRRRR V0GGGGGG

>１フレーム分のデータ完成する前に先頭ビットがHighになった場合、そのフレームの
>どこかで、データが欠落してます。


60fps対応版("偽トロキャプチャと車とかとか"の記事から抜粋)

>上画面と下画面がドットレベルで交互に出力されています。
>今まで使っていなかった前から２ビット目を上画面・下画面のフラグとしました。
>これで上記のように交互にデータが来てもどっちの画面のデータか判断できると思います。


V = VSync(垂直同期)
0 = NULL
R = 赤(0〜63)
G = 緑(0〜63)
B = 青(0〜63)

S = 画面 0:上画面 1:下画面(60fps対応版のみ)

初期版
V0RRRRRR V0GGGGGG V0BBBBBB V0RRRRRR V0GGGGGG V0BBBBBB V0RRRRRR V0GGGGGG V0BBBBBB ...

60fps版
VSRRRRRR VSGGGGGG VSBBBBBB VSRRRRRR VSGGGGGG VSBBBBBB VSRRRRRR VSGGGGGG VSBBBBBB ...

60fps版の例
10RRRRRR 10GGGGGG 10BBBBBB 11RRRRRR 11GGGGGG 11BBBBBB 10RRRRRR 10GGGGGG 10BBBBBB ...
